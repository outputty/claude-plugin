# Product memory

Every file here carries YAML frontmatter with a `type`. Open one file, not the set.

| File | `type` | Holds | Open it when |
| --- | --- | --- | --- |
| [product.md](product.md) | Product | North Star + Language | always — start here |
| [roadmap.md](roadmap.md) | Roadmap | feature status, deps ordered | planning, or "what's next" |
| [architecture.md](architecture.md) | Architecture | target program + seams | designing or writing code |
| [examples.md](examples.md) | Examples | the canonical worked examples | you are about to show an example |
| [lessons.md](lessons.md) | Lessons | what was tried and what killed it | repeat work, or when stuck |
| [claims/](claims/) | Claim | one external fact per file | a plan cites one by slug |

**Reuse an example verbatim.** Pin a new one in `examples.md` before you use it.

**Every ✅-shipped statement here was verified by a run.** Hold anything you add to that bar.
