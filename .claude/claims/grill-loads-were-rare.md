# Claim: Prose skill references do not load the skill

**Status:** valid · **Validated:** 2026-08-06 · **Scope:** laygo (consumer project) unless stated otherwise

## Statement

With spec.md phrasing the grill as 'use the skill's technique', the skill loaded 7 times in 24 days and never during the worst planning stretch, while SPEC documents were committed throughout.

## How it was validated

grep of laygo session transcripts for Skill-tool invocations naming grill, and reads of skills/grill/SKILL.md, against SPEC commit dates in git log.

## How to revalidate

Re-run the transcript grep over the current period; the claim is stale if load counts track SPEC activity.
