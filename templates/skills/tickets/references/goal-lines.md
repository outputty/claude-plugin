# The goal lines

Step 3 prints one of these, with the numbers filled in.

One ticket:

/goal ticket #<n> is built by following /build <n>: its PR is open and ready for review with the docs layer last and each Implementation-criteria case's real output pasted; or a question to the user is open and not yet answered; or stop after 60 turns

Several tickets picked together, in the order given:

/goal tickets #<n>, #<m> are built in that order by following /build <n> <m>: each ticket's PR is open and ready for review with its docs layer last and its Implementation-criteria cases' real output pasted; or a question to the user is open and not yet answered; or stop after 120 turns
